How to get a model

  1. Open Hugging Face · GGUF models in your browser.
  2. Search for a small instruct model in GGUF format, for example Qwen2.5 0.5B Instruct GGUF, Llama 3.2 1B Instruct GGUF or SmolLM2 1.7B Instruct GGUF.
  3. Open the model page and tap Files and versions.
  4. Download one file that ends in .gguf. Choose Q4_K_M (or Q4_0): the best balance of size and quality.

Which size? Phones: 0.5B to 1.5B. Laptops: up to about 3B. Bigger models are slow in a browser and need more memory than the file size.

More info: About the GGUF format · llama.cpp (local AI engine)

How to install a model

  1. Tap the ＋ button next to the message box (or Manage models above) and choose the file.
  2. Pick the downloaded .gguf file from your device.
  3. Wait for the progress bar to finish. The file is now stored inside the app.
  4. Pick the model in the selector next to the send button.
  5. Send a message. The first reply takes longer because the model loads into memory.

You can delete the original download afterwards. Tap Remove on a model to free its space. If it fails, check the file really ends in .gguf and try a smaller one.
